# ACE Programming – Mini Quiz App

A simple Python command-line quiz application that asks multiple-choice questions and keeps track of the user's score.

## 📌 Project Description

The Mini Quiz App displays questions one at a time and allows the user to select an answer.

The program checks the user's answer, updates the score when the answer is correct, and displays the correct answer when the user gives a wrong answer.

At the end of the quiz, the program displays the final score and a performance message.

The questions are stored separately in a JSON file instead of being directly written inside the main Python program.

## 🚀 Features

- Contains 10 multiple-choice questions
- Displays one question at a time
- Displays four options for each question
- Accepts the user's answer
- Checks whether the answer is correct
- Keeps track of the score
- Displays the correct answer when the user is wrong
- Displays the current question number
- Displays the final score
- Gives a performance message based on the score
- Stores questions separately in a JSON file
